# Vitamin Tracker

PWA-заготовка для учёта приёма витаминов.

## Локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Публикация (GitHub Pages)

1. Создай репозиторий `vitamin-tracker` на GitHub и запушь `main`.
2. В Settings → Pages выбери Source: **GitHub Actions**.
3. После пуша workflow задеплоит сайт на:
   `https://<username>.github.io/vitamin-tracker/`

На телефоне открой эту ссылку → «На экран Домой» / Install app.
