# Vitamin Tracker (Водоросли)

PWA для приёма **спирулины** и **хлореллы** через день.

## Возможности

- Чередование: сегодня один вид, завтра другой
- Отметка приёма на сегодня
- История с ручным внесением и сменой вида
- Смена расписания («поменять местами»)

## Локально

```bash
npm install
npm run dev
```
